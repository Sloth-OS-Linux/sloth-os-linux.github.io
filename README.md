# Sloth OS website and user documentation

This repository contains the public Sloth OS website and tester guides. The OS source code remains in [bathorizsolt/sloth-os](https://github.com/bathorizsolt/sloth-os).

- **Website:** https://sloth-os-linux.github.io/
- **Guides:** published from the `docs/` directory
- **Status:** pre-release; no public ISO download is available yet

## GitHub Pages

The workflow in `.github/workflows/pages.yml` deploys `docs/` to GitHub Pages when changes reach `main`. If the first deployment does not start automatically, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source.

## Documentation maintenance

The guides describe the current project state and avoid promising an installer or compatibility that is not ready. Keep the release status, installation guidance, and privacy details in sync with the OS source repository and roadmap.

The project

Can I download Sloth OS now?

There is no official public ISO download yet. The project roadmap lists real-machine testing, public release preparation and ISO hosting as unfinished work. Check GitHub for current progress.

Is Sloth OS ready for my main computer?

No. It is a pre-release project and important paths still need end-to-end testing on real hardware. Explore it only in a virtual machine or on a spare test computer, and keep backups.

What is Sloth OS built on?

It is based on Universal Blue's Fedora Kinoite images with KDE Plasma, with AMD/Intel and NVIDIA image variants. Flatpak is the app format used for the optional desktop apps.

Apps and games

Will every Windows program work?

No compatibility layer can promise that. Sloth OS tries different per-app settings, but some programs depend on Windows drivers, kernel features, anti-cheat, DRM or services that are not available. Support is experimental.

Do I need Steam to run Windows programs?

The Sloth OS .exe handler is designed to launch Windows programs without Steam, using Proton through umu-launcher and a system Wine fallback. Steam may still be useful for games and is one of the optional apps in the Welcome wizard.

Does Sloth OS send my Windows app names?

No. If you opt in to sharing, the app name is hashed on your machine. The report contains the hash, GPU manufacturer, a compatibility setting and whether it worked. Read the privacy guide.

Updates

What does “atomic update” mean?

The system updates as a complete image. Sloth OS is designed to keep a previous deployment available so you can roll back from the boot menu if an update causes a problem. This still needs end-to-end release testing.

Does it support NVIDIA?

The project builds an NVIDIA image variant and is working on automatic NVIDIA handling. The roadmap still calls for testing on an NVIDIA machine, so support should be treated as experimental.

Privacy and contributions

Can I use shared compatibility settings without sharing?

Yes. Downloading the shared static knowledge file is separate from sending reports. Opt-in sharing can be changed in Sloth Center.

Where can I report a problem?

When the repository is available to you, open an issue on GitHub Issues and include the Sloth OS version, hardware details and steps to reproduce. Do not attach private files or diagnostic logs that contain personal information.

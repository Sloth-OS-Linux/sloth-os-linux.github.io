The project

Can I download Sloth OS now?

Yes. Sloth OS 1.2.1 is available from the download page, with its SHA-256 checksum and USB installation guide.

Is Sloth OS ready for my main computer?

Sloth OS 1.0 was the first public release; 1.2 is the current one. The whole-disk install (with or without encryption), installing next to Windows, updates, backups and the Welcome wizard are tested on real computers, and NVIDIA computers have been tried with Secure Boot turned off. Every PC is different: try it from the USB stick first, and keep backups.

Will it run on my computer?

Most likely, if it is a 64-bit PC from 2013 or later that starts in UEFI mode, with at least 4 GB of memory and 64 GB of disk space. For games, 16 GB of memory and a recent AMD, Intel or NVIDIA (GTX 16 / RTX 20 series or newer) graphics card are recommended. Full details: system requirements. You can always try it from the USB stick first.

Where can I download it?

On the download page, together with a step-by-step guide for making the USB stick on Windows, macOS or Linux.

Which languages does it support?

The installer, the Welcome wizard and Sloth Center are translated into 50 languages. Native speakers are welcome to review the translations.

What is Sloth OS built on?

It is based on Universal Blue's Fedora Kinoite images with KDE Plasma, with AMD/Intel and NVIDIA image variants. Flatpak is the app format used for the optional desktop apps.

Apps and games

Will every Windows program work?

No compatibility layer can promise that. Sloth OS tries different per-app settings, but some programs depend on Windows drivers, kernel features, anti-cheat, DRM or services that are not available. Support is experimental.

Why does Sloth OS suggest Heroic for Epic and GOG?

The Windows versions of the Epic Games Launcher and GOG Galaxy do not run reliably here. Heroic is a native launcher for both stores, with the same library and sign-in. If you open the Windows installer anyway, Sloth OS suggests Heroic first and still lets you continue.

Do I need Steam to run Windows programs?

The Sloth OS .exe handler is designed to launch Windows programs without Steam, using Proton through umu-launcher and a system Wine fallback. Steam may still be useful for games and is one of the optional apps in the Welcome wizard.

Does Sloth OS send my Windows app names?

No. If you opt in to sharing, the app name is hashed on your machine. The report contains the hash, GPU manufacturer, a compatibility setting and whether it worked. Read the privacy guide.

Updates

What does “atomic update” mean?

The system updates as a complete image, downloaded in the background and applied at the next restart. Only images signed by Sloth OS are accepted. The previous version is kept, and if a start fails the boot menu appears so you can go back to it.

How big is an update?

Since 1.2 an update downloads only the parts of the system that changed: a typical one is a few hundred MB, a bigger one (for example a new Fedora base) can be a few GB. The first update from 1.1 to 1.2 downloads the whole system once, about 4.5 GB. On a mobile or other metered connection the automatic update waits and Sloth Center asks before downloading, and in Sloth Center → Updates you can choose the hour the automatic update runs and quiet hours without restart reminders.

Can I get back a file I deleted?

Yes. Sloth OS takes automatic snapshots of your home folder. Right-click a file or folder in the file manager and choose “Previous versions”. For a copy outside the computer, set up a backup to an external drive in Sloth Center → File backup.

Can I reset my computer?

Yes, from Sloth Center → Reset this PC, or from the boot menu (press Esc while the computer starts) if Sloth OS no longer starts properly. You can keep your files and reset only the system and apps, or erase everything and start with a new account.

Back up first. When you keep your files, Sloth OS automatically takes a saved state of them before the reset, so you can bring anything back from “Previous versions”. When you erase everything, the saved states on the computer are erased too: copy what you need to an external drive or USB stick beforehand, otherwise there is nothing to restore it from.

Does it support NVIDIA?

Yes, there is a separate NVIDIA image. A computer with an NVIDIA card switches to it on its own and notifies you; the switch takes effect after a restart. With Secure Boot on, a blue “MOK management” screen appears once at that restart: choose Enroll MOK → Continue → Yes, type the password universalblue, then Reboot; Sloth Center → Drivers and hardware shows the same steps. It has not been tested on an NVIDIA machine yet: use it at your own risk. If something goes wrong, the previous version stays in the boot menu.

Privacy and contributions

Can I use shared compatibility settings without sharing?

Yes. Downloading the shared static knowledge file is separate from sending reports. Opt-in sharing can be changed in Sloth Center.

How can I support Sloth OS?

Sloth OS is free and made in spare time. If you like it, you can support its development with a beer on Ko-fi (PayPal or card). Reporting problems from Sloth Center → Feedback helps just as much.

Where can I report a problem?

Open Sloth Center → Feedback, choose problem, idea or other, and describe it in your own words. You don't need a GitHub account. Each report becomes a public issue in Sloth-OS-Linux/feedback, without your name. If you attach the computer information and log, they are not public: only the developers can open them, and they are deleted after 30 days.

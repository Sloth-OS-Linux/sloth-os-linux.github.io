Download

Sloth OS 1.0.2 is being prepared. The download link will return after the new ISO is uploaded and its checksum is verified. Please do not download the older ISO in the meantime.

The same file works for every computer. On a computer with an NVIDIA graphics card, Sloth OS switches to its NVIDIA version by itself after installing and tells you when to restart.

Be honest with your data. Sloth OS 1.0 is new. Installing next to Windows works in our tests but has not yet been tried on many real Windows computers, and NVIDIA computers have not been tested yet. Back up anything important first.

Computer64-bit PC (x86_64) that starts in UEFI mode: almost every computer from 2013 or later. Older BIOS-only PCs and ARM computers (Apple Silicon Macs, Snapdragon laptops) are not supported.
Processor2 cores4 cores or more
Memory4 GB16 GB

NVIDIA: Sloth OS uses NVIDIA’s open driver, which supports GeForce GTX 16 and RTX 20 series cards and newer. Older NVIDIA cards (GTX 10 series and earlier) are not supported by it yet. NVIDIA computers have not been tested yet.

Next to Windows, plan at least 64 GB of free space for Sloth OS, on top of what Windows needs.

Make the USB stick

Use Fedora Media Writer. It is free and works the same on Windows, macOS and Linux:

  1. Install and open Fedora Media Writer.
  2. Choose Select .iso file and pick the Sloth OS file you downloaded.
  3. Choose your USB stick and click Write. It takes 5–15 minutes.

On Windows, Rufus works too: select the file, click Start, and if Rufus asks, choose Write in DD Image mode.

Ventoy works too (tested with Ventoy 1.1.18): copy the ISO file onto the Ventoy stick and choose it in Ventoy’s menu (“Boot in normal mode”). With Secure Boot on, Ventoy asks once to enroll its own key; follow Ventoy’s instructions on its first start.

Start from the USB stick

  1. Plug the USB stick in and restart the computer.
  2. While it starts, press the boot menu key: usually F12 (Dell, Lenovo, Acer), F9 (HP), F8 or Esc (ASUS), F11 (MSI). On Windows you can also hold Shift while clicking Restart, then choose Use a device.
  3. Pick the USB stick (sometimes listed as “UEFI: …”).

Secure Boot can stay on. On a computer with an NVIDIA graphics card, Sloth OS installs the NVIDIA driver after installing and asks you to restart. At that restart a blue screen (“MOK management”) appears once: choose Enroll MOK → Continue → Yes, type the password universalblue, then choose Reboot. This allows the NVIDIA driver to load with Secure Boot on. Sloth Center → Drivers and hardware explains the same steps, and can prepare them again if you missed the screen. Computers without an NVIDIA card never see this screen.

Sloth OS starts with a choice: Try Sloth OS (nothing is changed on your computer) or Install Sloth OS.

Install

The installer asks for your language, keyboard and time zone, your name and password, and where to install:

  • The whole disk: everything on it is erased. Tested on real computers.
  • Next to Windows: Windows gets smaller, and a menu at startup lets you choose. Before this, start Windows once and turn off Fast startup; if your Windows drive is encrypted with BitLocker, have your recovery key ready.
  • Encrypt the disk (optional): Sloth OS asks for a password every time the computer starts.

After a restart, the Sloth Welcome wizard helps you choose your apps. Read Getting started for what comes next.

Check the download (optional)

The SHA-256 checksum for Sloth OS 1.0.2 will be published here when the ISO upload is complete. On Windows, you can compare it with Get-FileHash sloth-os-1.0.2-x86_64.iso. Fedora Media Writer also checks the USB stick after writing it.

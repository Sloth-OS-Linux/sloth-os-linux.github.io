Release notes

What is new in 1.2 (October 28, 2026)

Much smaller updates, and Sloth Center learned to help with games, network folders and problems.

  • Much smaller updates: an update downloads only the parts of the system that changed. On a real machine a typical update was about 300 MB instead of 2–4 GB, and the installer shrank from 7.0 GB to 5.2 GB. Coming from 1.1, the first update downloads the whole system once (about 4.5 GB); after that, updates are small.
  • Help: the most common problems answered offline, in every language, each with a button to the page that fixes it.
  • “Will it run?” on the Games page: about 20 000 games with how well they run, from other players’ reports, the anti-cheat and the source of every answer. When the makers block Linux, it says so and whom to ask.
  • Move a Steam game to another drive without downloading it again.
  • Network folders: a NAS or another computer’s shared folder in the file manager’s side panel, found by itself or typed as \\NAS\Photos. If a NAS shares nothing yet, it tells you which setting to turn on.
  • Quiet hours for restart reminders, and the hour the automatic update downloads.
  • Display and sound profiles: save “Desk”, “TV” or “Headset” and switch with one click.
  • Settings to a file and back: the look, the profiles, the quiet hours and your apps, which Sloth Welcome installs again on a new computer.
  • Clean up shows each item and its size first, and deletes only what you tick.
  • Installer: it checks the computer on its first page (UEFI mode, memory, a laptop on battery), and its last steps say what is happening instead of standing at 80%.
  • Windows programs: WinUI 3 / .NET MAUI programs, which do not run on Linux yet, are recognized and explained; from the USB stick, Windows programs start sooner and use less memory.
  • Every new text is in all 50 languages.
What is new in 1.1 (October 27, 2026)

The biggest update since 1.0: Sloth Center learned most of what people look for in Windows' Settings, and Windows programs install and start more reliably.

  • Updates that finish: a system update could stop halfway; this is fixed and checked with a full 2.3 GB update on a real machine. The Updates page shows how big the update is and asks before downloading on a mobile or other metered connection.
  • A guided tour: the first-run guide in Sloth Center lights up the pages it talks about, one step at a time.
  • Appearance: change the taskbar layout and colors any time. New layout: Ubuntu-like, with a top bar and a floating dock.
  • Displays, Sound and Bluetooth: switch a 144 Hz monitor to its full refresh rate with one button, turn on VRR and HDR, pick and test speakers and microphone, turn on Bluetooth and see your devices' battery.
  • Wi-Fi check: finds the problem step by step in plain language, also a hotel network that wants a sign-in.
  • Startup programs and app permissions: see what starts when you sign in, and which apps can use the camera, the microphone and your location.
  • File backup: restore a file or find deleted ones in a few clicks, and check that the backup can really be read back.
  • Installer: with more than one screen it asks which is the main one, and on other disks you can pick the Linux partitions one by one.
  • Windows programs: double-click a disc image (.iso) to open it like a disc, installers that crash are tried again with a fix, and an installer that opens its program at the end no longer keeps you waiting.
  • The FPS display while playing also shows temperatures and memory, and every new text is in all 50 languages.

Already running Sloth OS? You get 1.2 as a normal update, no reinstall needed. Coming from 1.1 or earlier, that first update is a one-time download of about 4.5 GB; leave the computer on and connected until it is ready.

NVIDIA: Sloth OS uses NVIDIA’s open driver, which supports GeForce GTX 16 and RTX 20 series cards and newer. Older NVIDIA cards (GTX 10 series and earlier) are not supported by it yet. NVIDIA computers have been tried with Secure Boot turned off.

Next to Windows, plan at least 64 GB of free space for Sloth OS, on top of what Windows needs.

Make the USB stick

Use Fedora Media Writer. It is free and works the same on Windows, macOS and Linux:

  1. Install and open Fedora Media Writer.
  2. Choose Select .iso file and pick the Sloth OS file you downloaded.
  3. Choose your USB stick and click Write. It takes 5–15 minutes.

On Windows, Rufus works too: select the file, click Start, and if Rufus asks, choose Write in DD Image mode.

Ventoy works too (tested with Ventoy 1.1.18): copy the ISO file onto the Ventoy stick and choose it in Ventoy’s menu (“Boot in normal mode”). With Secure Boot on, Ventoy asks once to enroll its own key; follow Ventoy’s instructions on its first start.

Start from the USB stick

  1. Plug the USB stick in and restart the computer.
  2. While it starts, press the boot menu key: usually F12 (Dell, Lenovo, Acer), F9 (HP), F8 or Esc (ASUS), F11 (MSI). On Windows you can also hold Shift while clicking Restart, then choose Use a device.
  3. Pick the USB stick (sometimes listed as “UEFI: …”).

Secure Boot can stay on. On a computer with an NVIDIA graphics card, Sloth OS installs the NVIDIA driver after installing and asks you to restart. At that restart a blue screen (“MOK management”) appears once: choose Enroll MOK → Continue → Yes, type the password universalblue, then choose Reboot. This allows the NVIDIA driver to load with Secure Boot on. Sloth Center → Drivers and hardware explains the same steps, and can prepare them again if you missed the screen. Computers without an NVIDIA card never see this screen.

Sloth OS starts with a choice: Try Sloth OS (nothing is changed on your computer) or Install Sloth OS.

Install

The installer asks for your language, keyboard and time zone, your name and password, and where to install:

  • The whole disk: everything on it is erased. Tested on real computers.
  • Next to Windows: Windows gets smaller, and a menu at startup lets you choose. Before this, start Windows once and turn off Fast startup; if your Windows drive is encrypted with BitLocker, have your recovery key ready.
  • Encrypt the disk (optional): Sloth OS asks for a password every time the computer starts.

After a restart, the Sloth Welcome wizard helps you choose your apps. Read Getting started for what comes next.

A little Windows help

Keep the apps
you count on.

Open a Windows .exe or .msi and Sloth OS tries to find a setup that works for that program. It uses Proton through umu-launcher behind the scenes, with a system Wine fallback when needed.

Sharing is
opt in.

Sloth OS can share anonymous Windows app settings to help other users. You choose during setup, can switch it off later, and still receive the shared settings either way.

THE PRINCIPLE

If you need the terminal,
that’s my fault.

I’m building Sloth OS on my own. Everyday tasks should be available from the desktop, without asking people to learn command-line tools. If the terminal is required, I still have work to do.

The Sloth OS look

Matte silver.
Charcoal dark.

The default desktop uses the Sloth Silver Dark colour scheme: graphite surfaces, soft silver text and highlights, and restrained blue links. The source also includes light, white, black, night, mist and sage variations.

Atomic by design

Sloth OS is built on Fedora Atomic. Updates are applied as a system image, with a previous deployment available for rollback.

How updates work ↗

Sloth Center

Every setting,
one window.

Sloth Center sits on the taskbar next to the file manager and the app store. Anything you would otherwise do in a terminal has a button here: updates, drivers, backups, accounts, disks and Windows programs.

01 / UPDATES
↻

Quiet, verified updates

The system updates in the background and only accepts images signed by Sloth OS. A notification tells you when an update is ready, with a “Restart now” button.

02 / FILE HISTORY
◷

Previous versions

Your home folder is snapshotted automatically. Right-click a file or folder and choose “Previous versions” to bring back what you deleted or changed. Backups to an external drive are one click away.

03 / RESET
⟲

Reset this PC

Start over without a USB stick: keep your files and reset only the system settings, or erase everything and create a fresh account. Keep a backup: erasing everything also erases the saved states on the computer.

04 / HARDWARE
⚙

Drivers and devices

NVIDIA machines switch to the NVIDIA image on their own. Game controllers, printers, scanners, firmware updates and phone pairing are managed from the desktop.

05 / YOUR FILES
☁

Cloud and moving in

OneDrive and Google Drive appear as normal folders. Coming from Windows? Sloth OS can copy your Desktop, Documents, Pictures and browser bookmarks from the Windows drive.

06 / SIGN-IN
⚿

PIN, fingerprint, encryption

Sign in with a PIN or a fingerprint, on the login and lock screen alike. The installer can encrypt the whole disk with a password asked at startup.

Windows program support

Double-click.
Sloth OS takes it from there.

The project is building an .exe and .msi handler that tries compatible settings per program using Proton via umu-launcher, with system Wine as a fallback. Launchers such as Battle.net, EA app and Ubisoft Connect have their own recipes. When a program has a better Linux version (Discord, Chrome, Teams, Epic and GOG through Heroic), Sloth OS offers that first. Compatibility is experimental; some apps and games will not work.

Your choice, always

Sharing is
opt in.

If enabled, Sloth OS reports a local hash of the app name, the GPU manufacturer, a compatibility setting, the outcome, and a random machine ID. The app name itself is not sent. Sharing can be changed in Sloth Center.
